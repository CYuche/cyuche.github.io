隱私權政策

應用程式：rclone-sync

維護者：CYuche

工具用途

本工具供維護者個人使用，透過 Docker 中的 rclone， 將指定的本機或 FTP 檔案傳送至經授權的 Google Drive。

存取的資料與用途

工具依使用者設定，處理來源檔案內容，以及 Google Drive 的檔案名稱、路徑、大小、修改時間與其他同步所需資訊。 Google Drive 授權用於列出、建立和更新檔案； 啟用鏡像同步時，也可能刪除目的端多餘的檔案。 即使授權範圍允許存取其他檔案，同步作業仍依指定路徑執行。

資料儲存與傳輸

同步資料經執行 Docker 的主機傳送至 Google Drive。 OAuth 權杖與連線憑證保存在執行者管理的 rclone 設定中， 不會刻意發布到本網站或公開儲存庫。 執行紀錄可能包含檔案名稱、路徑與錯誤資訊。

資料分享

本工具不將同步資料出售或用於廣告。 資料處理涉及使用者選定的來源服務、執行主機及 Google Drive； 各服務仍適用其自身的隱私權政策。

保留與刪除

同步至 Google Drive 的檔案會保留至使用者刪除， 或依同步設定被移除。設定檔、憑證及執行紀錄由執行者管理， 不設自動刪除期限。

撤銷授權

使用者可透過 Google 帳戶的第三方連線設定 撤銷本工具的存取權。 撤銷授權不會自動刪除已傳送的檔案； 如需移除，請另行刪除雲端檔案及本機設定。

本網站

本網站為 GitHub Pages 上的靜態說明頁， 不要求訪客提交 Google 或 FTP 憑證， 也未加入分析或廣告追蹤程式。 GitHub 可能依其隱私權政策處理網站存取紀錄。

聯絡方式與更新

如有問題，可透過 GitHub Issues 聯絡維護者，請勿在公開留言中提供憑證或私人檔案。 工具用途或資料處理方式變更時，將更新本頁。
